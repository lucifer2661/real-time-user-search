# Real-Time User Search Filter

A simple frontend project that dynamically filters user cards based on search input.
This project demonstrates **DOM manipulation, event handling, and array filtering in JavaScript**.

---

## 🚀 Features

* Real-time search filtering
* Dynamic card rendering using JavaScript
* Case-insensitive search
* Displays **"No users found"** when there are no matches
* Responsive card layout
* Clean UI with blur effect on cards

---

## ⚙️ How It Works

1. User types in the search input field.
2. JavaScript listens for the **input event**.
3. The `filter()` method creates a new array of matching users.
4. The `showUsers()` function dynamically renders the cards.
5. If no matches exist, the UI shows **"No users found"**.
